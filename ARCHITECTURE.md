# Архитектура PulseBeat

Проект использует принципы ООП, интерфейсы и паттерны проектирования. Основная идея: контроллеры JavaFX отвечают за экран, а работа с данными, импортом и порядком воспроизведения вынесена в отдельные модули.

## 1. TrackRepository

Интерфейс: `com.repository.TrackRepository`

Назначение: отделяет контроллер от конкретного способа хранения треков.

Реализации:
- `SqlTrackRepository` - работает с базой данных через существующий `TrackDAO`.
- `CachedTrackRepository` - добавляет кэширование списка треков, чтобы не обращаться к базе лишний раз.
- `ReadOnlyTrackRepository` - режим только для чтения, запрещает добавление и удаление треков.

Паттерны: Repository, Adapter, Decorator.

## 2. TrackMetadataReader

Интерфейс: `com.metadata.TrackMetadataReader`

Назначение: получает название, исполнителя и альбом из музыкального файла.

Реализации:
- `FileNameTrackMetadataReader` - берет данные из имени файла, например `Artist - Title.mp3`.
- `TagTrackMetadataReader` - читает ID3-теги MP3 через библиотеку JAudioTagger.
- `FallbackTrackMetadataReader` - последовательно пробует несколько читателей и выбирает первый успешный результат.

Паттерны: Strategy, Chain of Responsibility.

## 3. PlaybackOrderStrategy

Интерфейс: `com.playback.PlaybackOrderStrategy`

Назначение: определяет, какой трек включить следующим или предыдущим.

Реализации:
- `SequentialPlaybackOrderStrategy` - обычное последовательное воспроизведение.
- `ShufflePlaybackOrderStrategy` - случайный порядок.
- `RepeatPlaybackOrderStrategy` - повтор текущего трека.

Паттерн: Strategy.

## 4. ApplicationFactory

Класс: `com.factory.ApplicationFactory`

Назначение: создает готовые зависимости для контроллеров и утилит. Благодаря этому в `MainController` не нужно вручную собирать все реализации.

Паттерн: Factory.



В программе есть 3 интерфейса, и у каждого по 3 реализации. Это позволяет менять поведение программы без переписывания контроллеров: можно заменить источник треков, способ чтения метаданных или порядок воспроизведения. Контроллер работает с абстракциями, а конкретные классы создаются фабрикой.
