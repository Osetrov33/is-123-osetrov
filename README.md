# PulseBeat - Музыкальный плеер на Java

![Java](https://img.shields.io/badge/Java-17-blue)
![JavaFX](https://img.shields.io/badge/JavaFX-21-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

## Описание
PulseBeat — настольное приложение для управления локальной музыкальной медиатекой.  
Программа позволяет:

- Регистрацию и вход пользователей
- Импорт MP3-файлов
- Просмотр медиатеки и избранного
- Поиск треков по названию и исполнителю
- Воспроизведение аудиофайлов с управлением очередью
- Добавление и просмотр отзывов
- Редактирование метаданных треков

## Технологии
- Java 17
- JavaFX 21
- Maven
- JDBC (Firebird/Red Database через Jaybird)
- BCrypt для хеширования паролей
- JAudioTagger для чтения метаданных MP3

## Архитектура
Проект построен с применением объектно-ориентированных принципов и паттернов проектирования:

- **Repository** — для работы с треками
- **DAO** — доступ к базе данных
- **Strategy** — выбор порядка воспроизведения треков
- **Factory** — создание зависимостей
- **Decorator** — кэширование репозитория
- **Chain of Responsibility** — чтение метаданных
